# AYAZ.EXE - Project Specification

## Overview
AYAZ.EXE is a production-quality, interactive developer portfolio. It combines a professional presentation of MERN stack skills and problem-solving abilities (170+ LeetCode problems) with an original gaming and anime-inspired interactive experience.

## Target Audience
**Primary:** Recruiters and Hiring Managers. Critical information (Name, Role, MERN skills, Projects, LeetCode stats, Resume, GitHub, LinkedIn, Contact) must be immediately accessible without forcing interaction with game elements.
**Secondary:** Developers and Peers. The interactive elements, mini-game, and aesthetic serve to wow visitors and demonstrate technical frontend capabilities.

## Personality & Vibe
- MERN Stack Developer
- Gamer (Spider-Man, Valorant)
- Competitive/Problem Solver (170+ LeetCode)
- Tactical, agile, and dynamic

## Visual Direction
The portfolio should feel like an original tactical digital interface with agile web-inspired motion.

**Use:**
- Thin connecting lines and animated SVG paths
- Geometric brackets, subtle crosshair motifs
- Small system labels, coordinate-like decorative metadata
- Restrained red highlights
- Glass panels (Glassmorphism)
- Asymmetrical card layouts
- Subtle grain/noise overlays
- Occasional diagonal cuts
- Smooth scroll transitions, hover interactions, small interactive discoveries

**Do NOT use:**
- Literal spider webs everywhere
- Spider or superhero logos
- Copied FPS HUDs
- Excessive neon or glowing effects
- Giant background characters

## Important Copyright Rules
- **DO NOT COPY:** Spider-Man artwork, Marvel logos, Spider-Man character renders, Valorant logos, Valorant agent artwork, Riot Games UI, copyrighted game screenshots, or copyrighted UI designs.
- The visual identity must be 100% original, taking only *abstract inspiration* (movement feel, tactical layout, HUD aesthetics).

## Main Sections
1. **BOOT / HERO:** Initial landing, tactical boot sequence, immediate recruiter info.
2. **PLAYER PROFILE:** About me, quick stats, resume download.
3. **MISSIONS / PROJECTS:** Standard list/grid of projects with tech stacks and links.
4. **WEB OF PROJECTS:** Interactive node-based or web-like visualization of projects (Spider-Man inspired).
5. **TRAINING / DSA:** LeetCode stats (170+ solved), problem breakdown.
6. **ABILITIES / DSA PATTERNS:** Key algorithms and data structures mastered.
7. **LOADOUT / TECH STACK:** MERN stack focus, tools, languages.
8. **DISCOVERIES:** Small interactables/easter eggs scattered throughout.
9. **ARCADE / MINI GAME:** One simple, original HTML5 Canvas mini-game.
10. **QUEST LOG:** Timeline or upcoming goals/current learning.
11. **MISSION COMPLETE / CONTACT:** Footer, contact form, social links.
