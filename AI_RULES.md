# AI Development Rules

## 1. Recruiter Priority
Always ensure that critical information (Resume, Links, Skills, Projects, LeetCode stats) is immediately visible and accessible. Do not hide this behind complex interactions, games, or long animations.

## 2. Strict Copyright Compliance
- NEVER generate, suggest, or include copyrighted material (Spider-Man, Valorant, Riot Games, Marvel).
- Use abstract descriptions (e.g., "tactical red accent", "agile web-like transition") instead of direct references in code or assets.

## 3. Technology Constraints
- Use React, JS, standard CSS, Anime.js, and Canvas API.
- Do NOT install Tailwind, Three.js, Redux, or other heavy libraries unless explicitly requested.
- Do NOT build a backend.

## 4. Code Architecture
- Keep UI components separate from data.
- Read from the `src/data/` directory for content.
- Write clean, modular, and well-commented code.

## 5. Aesthetic Adherence
- Maintain the dark minimal, glassmorphic, thin-bordered style.
- Use the subtle red accent sparingly but effectively.
